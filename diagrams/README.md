# Diagrams

These Mermaid files keep the editable sources used by the Korean and English documents.

| File | What it shows |
|---|---|
| `architecture.mmd` | The public version of the actual service order and Redis uses |
| `message-flow.mmd` | `messageId` moving through the end-to-end send path |
| `token-refresh.mmd` | Send and access-token refresh paths kept separate |
| `unregistered-flow.mmd` | The current FCM `UNREGISTERED` confirmation policy |

Names are intentionally general, but the diagrams do not add components that were not part of the implementation.
